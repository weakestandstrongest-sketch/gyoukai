# Gyoukai（業界）

広告やPRではなく、**決算データ**から企業と業界を読むための企業分析アプリのプロトタイプです。
`index.html` 1ファイルで動きます（ビルド不要）。

## 使い方

- `index.html` をブラウザ（Windows の Chrome / Edge、iPhone の Safari など）で開くだけで動きます。
- iPhone で使う場合は GitHub Pages などで公開し、Safari の「共有 → ホーム画面に追加」でアプリのように使えます。

## 画面

| タブ | 内容 |
|---|---|
| ホーム | ダッシュボード（ウォッチリスト・業界一覧・きょうの決算用語）。**上にスワイプ**（PCはボタン or 最下部でスクロール）すると黒背景のメニューが開く |
| ニュース | Instagram風のストーリー（業界別・自分で投稿可）とフィード（いいね・ダブルタップ・コメント・保存） |
| 業界 | 7業界・30社の過去5年の決算（グラフ／表／シェア構造）と、資本・提携・供給・競合の相関図 |
| 地方 | 簡略化した日本地図（都道府県タイル）から地方を選び、本社所在地・業種・売上高等を表示 |

### 収録業界

自動車 / 電機 / IT・通信 / 半導体・電子部品 / 総合商社 / 金融（銀行） / 小売

## データを追加・修正するには

`index.html` の `<script>` 内にある定数を編集します。

- `INDUSTRIES` … 業界ごとの企業と5年分の数値（単位：億円）、相関図の関係（`ext` と `edges`）
- `REGION_COS` … 地方ごとの企業（本社所在地・業種・売上高等）
- `STORIES` / `POSTS` … ニュース画面のストーリーとフィード

業界を1つ追加する場合は、`INDUSTRIES` に同じ形のオブジェクトを1つ足すだけで、
グラフ・表・シェア・相関図・ホームの業界タイルにすべて反映されます。

## 注意

- 財務数値は公表資料をもとにした**概数**です。就活・投資の判断に使う前に、各社の IR 資料・決算短信・有価証券報告書（[EDINET](https://disclosure2.edinet-fsa.go.jp/)）で必ず確認してください。
- 会計基準（IFRS・日本基準）や決算期が企業によって異なります。
- ストーリー投稿・いいね・コメントはそのブラウザの `localStorage` にだけ保存されます。
