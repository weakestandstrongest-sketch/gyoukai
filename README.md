# Gyoukai（業界）

広告やPRではなく、**決算データ**から企業と業界を読むための業界研究アプリです。
`index.html` を開くだけで動きます（ビルド不要）。

- 公開ページ（GitHub Pages）：https://weakestandstrongest-sketch.github.io/gyoukai/
- iPhone では Safari で開いて「共有 → ホーム画面に追加」するとアプリのように使えます。

## 画面

| タブ | 内容 |
|---|---|
| ホーム | 白黒の1枚絵だけの画面。**上にスワイプ**（PCはドラッグ・ホイール・↑キー・「業界メニュー」）で黒いメニューが開く |
| ニュース | その日の経済ニュースを業界別のストーリーと一覧で表示。影響が考えられる業界（＋追い風／−逆風／±どちらも）つき。タップするとGyoukai内の記事画面で開くか、iPhoneのショートカットで「Gyoukaiで開く／Cometで開く」を選べる |
| 業界 | **詳しく見る**：21業界・70社の5年分の決算（グラフ・表・シェア・相関図）。企業をタップすると、グラフの下に企業の説明が出る。**全上場企業**：東証33業種・約3,700社を一覧・検索 |
| 地方 | 都道府県タイルの日本地図から地方を選び、注目企業と、本社がある**すべての上場企業**を都道府県・業種・社名で絞り込んで表示 |

## データ

| ファイル | 中身 | 更新方法 |
|---|---|---|
| `data/industries.js` | 詳しく見る業界の決算（FY2021〜FY2025＝2026年3月期）、企業の説明、相関図、地方の企業 | 手で編集 |
| `data/companies.js` | 全上場企業（コード・社名・市場・33業種・17業種・規模・本社の都道府県と市区町村・決算日） | GitHub Actions が毎朝自動更新 |
| `data/news.js` | その日のニュースの見出し・リンク・影響業界 | GitHub Actions が毎朝自動更新 |

### 自動更新（`.github/workflows/data.yml`）

毎朝 5:40（日本時間）に次の2つを実行し、変更があればコミットします。Actions タブの「Update data」→「Run workflow」で手動実行もできます。

- `scripts/build_companies.py`：日本取引所グループ「東証上場銘柄一覧」から全上場企業の一覧を作り、金融庁 EDINET コードリストから本社所在地と決算日を足す（住所に都道府県がない場合は `scripts/cities.json` の市区町村表で補う）
- `scripts/build_news.py`：Google ニュースの RSS から業界ごとのニュースを集め（使えないときは Yahoo!ニュース・NHK の RSS）、見出しのキーワードで影響業界を推定する。保存するのは見出し・媒体名・日時・リンクだけ。1件も取れなかった日は前回のデータを残す

## iPhone のショートカットでニュースを開く

ニュース画面の「開き方」→「ショートカットで選ぶ」をオンにすると、記事をタップしたときに次のショートカットが起動します（作り方はアプリ内にも表示）。

1. ショートカットアプリで新規作成し、名前を「Gyoukaiニュース」にする
2. 「メニューから選択」を追加し、項目を「Gyoukaiで開く」「Cometで開く」にする
3. Gyoukaiで開く：「URLエンコード」（ショートカットの入力）→「テキスト」`https://weakestandstrongest-sketch.github.io/gyoukai/?article=`＋エンコードしたテキスト →「URLを開く」
4. Cometで開く：「クリップボードにコピー」（ショートカットの入力）→「アプリを開く」でComet → アドレスバーに貼り付け
   （Comet をデフォルトのブラウザにしている場合や、ショートカットに Comet の「URLを開く」アクションがある場合は、それで直接開けます）

アプリは `shortcuts://run-shortcut?name=…&input=text&text=<記事URL>` でショートカットを呼び出し、`?article=<記事URL>` で開かれると記事画面を表示します。

### 業界を増やすには

`data/industries.js` の `industries` に同じ形のオブジェクトを1つ足すと、グラフ・表・シェア・相関図・メニューに反映されます。確認できていない年度は `null` にしておくと、グラフでは途切れ、表では「—」になります。

## 注意

- 決算の数値は決算短信や報道をもとにした**概数**です（2026年10月時点）。就活や投資の判断に使う前に、各社の IR 資料・有価証券報告書（[EDINET](https://disclosure2.edinet-fsa.go.jp/)）で確認してください。
- 会計基準（IFRS・日本基準）や決算期が企業によって異なります。
- ニュースの影響業界はキーワードによる自動推定です。
- ストーリー投稿・いいね・コメントはそのブラウザの `localStorage` にだけ保存されます。
